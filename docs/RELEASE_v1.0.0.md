# Spine → Codex 桌宠转换器 v1.0.0

首个正式版本，面向 Windows 10/11 用户。

## 下载

- `SpineCodexConverter-Full.zip`：推荐，解压即用，不需要 Node.js。
- `SHA256SUMS.txt`：下载完整性校验值。

请不要把 GitHub 自动生成的 `Source code.zip` 当作普通用户软件包。

## 首次使用

1. 完整解压 `SpineCodexConverter-Full.zip`。
2. 双击 `SpineCodexConverter.exe`。
3. 选择包含 `.skel`、`.atlas` 和贴图的文件夹。
4. 先检查动画，再执行转换。
5. 将生成的 `pet.json` 和 `spritesheet.webp` 一起安装到 Codex。

## 主要能力

- 自动动画映射和自定义映射配置。
- 九状态 Codex 精灵表输出。
- 人物缩放、裁边检测、预览图和转换报告。
- 完整桌面版与命令行模式。

素材不随项目提供。请只处理你有权使用和分发的模型。
